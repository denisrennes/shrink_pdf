Usage: shrink_pdf [OPTION]... PDF_FILE...
Shrink PDF_FILEs if possible.

OPTION
      --help                 display this help and exit
      --version              output version information and exit
      --press_any_key        the user will have to press any key at the end. 
                             Used when launched by GUI, e.g. right-click in
                             file manager.
  
Exit status:
 0  if OK,
 2  if serious trouble: Error, failure.
